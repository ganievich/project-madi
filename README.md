# Студенттердің үлгерімін талдау жүйесі

Python және **Tkinter** көмегімен жасалған үстелдік қосымша. Бағдарлама студенттердің үлгерімін бақылауға, орташа балын есептеуге және үлгерімі төмен немесе сабаққа қатысуы аз студенттерді («Тәуекел тобы») анықтауға арналған.

## Негізгі мүмкіндіктері
* **Студенттермен жұмыс:** Жаңа жазба қосу (`Ctrl+N`), бар деректерді өзгерту және жою (`Delete`).
* **Автоматты есептеу:** 3 бақылау бағасы бойынша орташа балл есептеледі; орташа балл 50-ден төмен немесе қатысу 70%-дан аз болса, **«Тәуекел тобы»** мәртебесі беріледі.
* **Іздеу, сүзгілеу және сұрыптау:** ID, аты-жөні, топ, орташа балл аралығы және тәуекел мәртебесі бойынша сүзгілеу; баған тақырыптарын басып өсу/кему ретімен сұрыптау.
* **Талдау терезелері:** Жалпы статистика (`Ctrl+T`), топтар бойынша орташа балл және **Үздік 3 студент** тізімі.
* **Файлдармен жұмыс:** Деректерді `.json` және `.csv` форматтарында ашу және сақтау (`Ctrl+O`, `Ctrl+S`), сондай-ақ алғаш іске қосылғанда 26 тест жазбасын автоматты қалыптастыру.
